# 今日は何作る？ - 自炊レシピ提案アプリ

学生の自炊向けに、安い・時短な定番レシピをTinder風のスワイプでlike/noするだけで、
好みを学習して提案してくれるPWA(スマホのブラウザで使えるアプリ)です。

## 特徴

- 🍳 **スワイプでlike/no**: ドラッグ、または画面下のボタンでレシピを評価
- 🧠 **好みを学習**: like/noの履歴からタグ(ジャンル・調理法・主材料など)の好みスコアを
  蓄積し、次に見せるレシピを重み付き抽選。一定確率で完全ランダムな提案も混ぜることで
  ワンパターン化を防止
- 💾 **サーバー不要**: すべてスマホのブラウザ内(localStorage)に保存。ログイン不要ですぐ使える
- 📱 **PWA対応**: ホーム画面に追加してアプリのように起動可能。簡易オフラインキャッシュ対応
- ❤️ **お気に入り一覧**: likeしたレシピを後から見返せる

## 技術構成

- [Next.js](https://nextjs.org)(App Router) + TypeScript
- Tailwind CSS
- [Framer Motion](https://www.framer.com/motion/)(スワイプのドラッグ操作)
- データ保存はブラウザの`localStorage`のみ(バックエンド/DBなし)

## セットアップ

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) をスマホまたはPCブラウザで開いてください。

スマホでは、ブラウザの「ホーム画面に追加」からアプリのように追加できます(PWA)。

## 推薦ロジックの仕組み

1. レシピにはあらかじめ「和食/中華」「炒め物/丼/麺」「鶏肉/豚肉/野菜多め」「時短/節約」
   などのタグが付いている(`src/data/recipes.ts`)
2. likeすると該当タグのスコアを+1、noすると-1(タグごとに-5〜+5でクランプ)
3. 次のレシピを選ぶとき、各レシピの保有タグの平均スコアに応じた重み付き抽選を行う
4. 25%の確率で完全ランダムに選ぶ(exploration)ことで、好みの偏りだけに支配されず
   新しいジャンルにも出会えるようにしている(ワンパターン化防止)
5. 一度見せたレシピは同じ周回中は再表示しない。全件見せ終わったら履歴をリセットして
   再度出現できるようにする

ロジック本体は `src/lib/recommend.ts` を参照してください。

## 今後の拡張アイデア

- **LLMハイブリッド化**: 普段はこのタグベース学習で無料運用しつつ、たまにClaude APIなど
  のLLMで「好みタグに合う新規レシピ」を生成して追加する。API利用料が発生するため、
  実装時は呼び出し頻度の制限やキャッシュを検討する
- **クラウド同期**: Supabase等を導入し、機種変更してもデータを引き継げるようにする
- **画像**: 現在はレシピごとに絵文字を表示しているだけなので、実際の調理写真を追加すると
  より魅力が伝わる
- **買い物リスト**: likeしたレシピの材料をまとめて買い物リスト化する機能
